How to Play Sudoku

The Objective

Fill the 9×9 grid so that every row, column, and 3×3 square box contains the numbers from 1 to 9 without repetition.

1️⃣

Rows & Columns

Each horizontal row and vertical column must contain every digit 1 through 9 exactly once.

⏹️

3×3 Boxes

Each of the nine 3×3 sub-grids outlined in thick borders must also contain 1 through 9.

✏️

Pencil Notes

Press N or click Notes to scribble candidate digits when a cell has multiple possibilities.

Keyboard Shortcuts

  • 1 - 9 : Enter number / candidate
  • Arrow Keys / WASD : Navigate cells
  • Delete / Backspace : Erase cell
  • N : Toggle pencil notes mode
  • H : Get a smart hint
  • Ctrl + Z / U : Undo
  • Ctrl + Y : Redo
  • Space / P : Pause game

Custom Board & Solver

Paste an 81-character puzzle string (using digits 1-9 and 0 or '.' for blanks), or click "Load Empty Grid" to enter numbers manually.
